# 📄 SahilPDF Studio

A modern, lightweight PDF toolkit built with **HTML, CSS, JavaScript, and Electron.js**.  
It brings essential PDF tools into one clean desktop application.

---

## 🚀 Features

### 📎 PDF Tools
- Merge multiple PDFs
- Split PDF pages
- Add digital signature to PDFs
- Drag & drop file support

### 🖥 PDF Reader (Desktop)
- Fast PDF rendering using PDF.js
- Smooth page scrolling
- Zoom in / zoom out support
- Lightweight and responsive UI

### ✍️ Signature Tool
- Upload or draw signature
- Drag & position anywhere on PDF
- Resize signature
- Export signed PDF

---

## 🧠 Tech Stack

- HTML5
- CSS3 (Dark UI system)
- Vanilla JavaScript
- PDF.js (rendering)
- PDF-Lib (editing PDFs)
- Electron.js (desktop app)
